# 言語アプリ

中国語（HSK 1〜3級）とスペイン語（DELE A1〜B1相当）を、依存関係なしで学べるブラウザアプリです。

公開版: https://nagomen.github.io/language-study-app/

## 起動方法

ブラウザで上記URLを開くか、ローカルで動かす場合は `スタート.command` をダブルクリックしてください。言語選択画面がブラウザで開きます。

初回のみmacOSに止められた場合は、ファイルを右クリックして「開く」を選択してください。

## デプロイ

GitHub Pages（`main` ブランチのルートをそのまま配信）です。更新はpushするだけで反映されます。

```
git add -A
git commit -m "変更内容"
git push
```

反映まで1〜2分かかります。ビルド状況は https://github.com/nagomen/language-study-app/actions で確認できます。

すべて相対パスで動く静的サイトなので、ビルド工程はありません。データのJSONは `cache: "no-cache"` で読み込むので、更新すれば再読み込みだけで反映されます（音声は名前と `?v=` で区別しているため強くキャッシュされます）。学習記録・チェックはブラウザのローカルストレージに保存されるため、公開版とローカル版では別々に記録されます。

## ファイル構成

ビルド工程はなく、HTMLが直接スクリプトを読みます。

```
/                HTMLと設定だけ（index / chinese / spanish、README、スタート.command）
css/             app.css（共通）・spanish.css（色の上書き）・portal.css（入口）
js/              shared.js ＋ chinese/ ＋ spanish/
data/            chinese/ ＋ spanish/ ＋ source/（生成元のTSV）
audio/           既存語の収録音声 ＋ sentences/（未収録語はブラウザ音声へ自動フォールバック）
scripts/         生成・検証・音声のスクリプト
docs/            調べた記録
```

| 場所 | 役割 |
|---|---|
| `index.html` / `css/portal.css` | 言語を選ぶ入口 |
| `chinese.html` / `js/chinese/*.js` | 中国語のページ |
| `spanish.html` / `js/spanish/*.js` / `css/spanish.css` | スペイン語のページ |
| `css/app.css` | 両方のページの見た目 |
| `js/shared.js` | 両方のページで使う共通処理 |
| `data/chinese/*.json` / `data/spanish/*.json` | 出題データ |
| `data/source/*.tsv` | 分類とスペイン語語彙の生成元（人が編集する原本） |
| `scripts/*` | データの生成と検証、音声の生成 |

`css/app.css` は中国語ページとスペイン語ページで共有します。ページごとに分けることも試しましたが、`@media` の上書きが「後に書いてあるほうが勝つ」順番に依存していて、分けると順序が入れ替わってモバイル表示が崩れました（実測で9画面）。安全に分けるには共通部分を両方へ複製するか生成スクリプトを足すことになり、得られるのはスペイン語ページの−6KB（gzip）だけなので、1つのままにしています。

`js/shared.js` には、`$`・`escapeHtml`・`shuffle`・日付キー、チェック（気になる単語）の保存と書き出し／読み込み、モバイルメニューの開閉が入ります。言語ごとの状態は持たないので、必要な値は呼び出し側が引数で渡します（保存キー・ラベル・言語名など）。

中国語ページは `js/chinese/main.js`、スペイン語ページは `js/spanish/main.js` を入口に、どちらも機能ごとのモジュールへ分かれています（スペイン語は `config` `state` `storage` `util` `audio` `words` `quiz` `checked` `progress` `review` `main` の11本）。中国語側の内訳はこちらです。

| モジュール | 中身 |
|---|---|
| `main.js` | 起動、データ読み込み、イベント登録、ハッシュのルーティング |
| `config.js` | レベル・模試・分類の定数、保存キー |
| `state.js` | 画面をまたいで持つ状態 |
| `storage.js` | ローカルストレージの読み書き |
| `audio.js` | 録音音声の再生と読み上げ |
| `words.js` / `categories.js` / `guide.js` | 単語帳・分類・コラム（解説ページ）の描画 |
| `grammar.js` | 文法（HSK2・3）の一覧・単元のページ・確認ドリル・進み具合 |
| `quiz.js` | 単語テスト |
| `practice.js` | 聴解・読解・作文トレーニングの出題と進行 |
| `mock.js` | 模試（抽選・セクションの時間管理） |
| `daily.js` | 毎日30語 |
| `checked.js` / `progress.js` / `review.js` | チェック・学習記録・振り返り |
| `util.js` | 小さな共通処理 |

ESモジュールなのでHTMLファイルを直接ダブルクリックでは動きません。`スタート.command`（ローカルサーバーを立てて開きます）か、公開版のURLから開いてください。

## 収録内容

- 中国語：2026年版HSK 1〜3級の公式1,000語（1級300・2級200・3級500）＋旧HSK 2.0だけにある補完33語。例文つきの単語帳、収録音声＋ブラウザ音声、HSK3の毎日30語、用途別の分類（35種）、文法ガイドと量詞の特設ページ、聴解・読解・作文、写真なし本番形式模試、間隔反復
- スペイン語：DELE A1相当150語、A2相当150語、B1相当300語。レベル別クイズ、検索、スペイン語音声、まちがい復習、学習記録

「単語帳」ページはHSK1〜3の1,033語を1語1枚のカードで表示します。内訳は2026年版の公式1,000語と、旧HSK 2.0の1〜3級にあって新版では独立見出しから外れた33語です。1枚に漢字・ピンイン・意味・分類ラベルと、例文（中国語・ピンイン・和訳・音声）が入ります。「旧版補完」だけの絞り込みにも対応します。

単語テストは解答するたびに、その単語を使った例文（中国語・ピンイン・和訳）を答えと一緒に表示し、その場で音声を再生できます。出題語は例文中でハイライトされます。例文は全1,033語に収録しています。ホームの「2026年新出語テスト」では、旧リストになかった430語（HSK1 86語・HSK2 88語・HSK3 256語）だけから10問を出題します。単語帳の「2026年新出」でも同じ430語に絞り込めます。

聴解の問題は、解答する前は音声を2回まで、**解答したあとは回数制限なしで**聞き直せます。

単語テスト・聴解／読解／作文トレーニング・間隔反復・模試・スペイン語クイズのすべてで、終了画面に「振り返り」が表示されます。1問ずつ、問題文（聴解は音声原文）、自分の回答、正解、解説を並べ、「すべて／まちがい」で絞り込めます。聴解・単語の問題は振り返り画面から音声を再生し直せます。

単語帳・テスト後の振り返りにある ✓ ボタンで、気になった単語にチェックを付けられます。チェックした単語は「チェック」ページに集まり、例文・正誤の記録・次の復習日を見返せるほか、そのまま単語テスト／読解／聴解で出題できます（誤答の選択肢は全1,033語から作るので、チェックが少なくても問題が成立します）。単語帳は「チェックのみ」で絞り込めます。スペイン語も単語一覧と振り返りからチェックでき、チェックした単語だけでテストできます。

チェックは学習記録とは別に保存され、学習記録のリセットでは消えません。消すときは「チェック」ページの「チェックをすべて解除」を使います。

チェックはブラウザのローカルストレージ（中国語 `hsk-checked-words`、スペイン語 `language-app-spanish-checked-v1`）に単語IDの配列として保存されるため、端末やURL（ローカル版と公開版）をまたいでは共有されません。「チェック」ページの「チェックを書き出す（JSON）」でファイルに保存し、別の環境で「チェックを読み込む」から取り込めます。読み込みは既存のチェックへの追加で、この単語データに無いIDは無視します。

中国語の語彙は、2025年11月公開・2026年7月施行の**新版HSK試験大綱**に合わせています。公式番号1〜300をHSK1、301〜500をHSK2、501〜1000をHSK3として収録します。さらに、旧版基準の外部模試にも対応するため、旧HSK 2.0の1〜3級にだけある33語（北京・唱歌・公共汽车・帽子・熊猫など）を「旧版補完」として加えています。`node scripts/build_hsk2026_vocab.mjs` で両方を再生成し、`node scripts/check_hsk_examples.mjs` で1,033語・級・例文を検証します。2026年版で新たに入った430語には、見出し語を自然な場面で使う個別例文を収録しています。うちHSK1〜2の174文と、HSK3の差し替え177文は `data/source/hsk2026/examples-new-hsk1-2.tsv`・`data/source/hsk2026/examples-new-hsk3.tsv` で管理します。HSK3の新出256語には単語・例文の収録音声があり、HSK1〜2の新出例文はブラウザの中国語音声で読み上げます。日本語語義のライセンスと出典は `data/source/hsk2026/NOTICE.md` に記載しています。

スペイン語語彙はInstituto Cervantes「Plan Curricular」の分野別インベントリを設計基準にした独自の学習用リストです。DELEには単一の公式固定出題語彙表がないため、「DELE相当」と表記しています。

## 毎日30語（HSK3）

ホームの上部にある「今日の30語」から始めます（URLは `#daily`）。2026年版HSK3の新出500語を、原則30語ずつ17日で一周する仕組みです（DAY 17は残りの20語）。旧600語版とは別の並びでDAY 1から始まり、旧版の「もう一度出す語」だけを引き継ぎます。

「今日の30リスニング」では、同じDAYの単語を使った例文を1文ずつ聞き、正しい日本語訳を4択から選びます。解答前は音声を2回まで聞け、解答後は中国語原文・ピンイン・日本語訳を見ながら何度でも聞き直せます。結果は通常の聴解と同じように学習記録と間隔反復へ反映されます。

- **日ごとの新出語は固定で、重複しません。** 500語を固定の並べ替えで17セットに分け、同じ単語が新出として二度出ないようにしています
- **前回まちがえた単語が翌日の出題に入ります。** 「もう一度出す語 → 今日の新出語」の順に1語1問ずつ出題します
- **正解した単語でも、気になる ✓ を付ければ次回に出ます。** テスト中の答え合わせ画面、終了後の振り返り、単語帳などから付けられます
- まちがえた単語も ✓ を付けた単語も**正解するまで持ち越し**ます
- **1セット終えたら、余力があればその日のうちに次へ進めます。** 完了後に出る「もう30語進む」で次の DAY に入ります。この追加回には復習を混ぜません
- テストをしなかった日は進みません。次に開いたときは同じ DAY から始まります
- **最後まで解かずにやめた回は完了になりません。** 同じ問題（その日の新出語＋持ち越し）をもう一度出題します
- ページには今日の新出語と前回のまちがいが、例文・音声・✓ボタンつきで並びます
- 17日ぶんを終えると完了表示に変わり、まちがえた単語の復習だけを続けられます
- 学習記録・間隔反復・まちがい復習にも通常のテストと同じように反映されます
- 進み具合はブラウザのローカルストレージ（`hsk3-daily-30-2026-v1`）に保存され、学習記録のリセットでは消えません。40語ずつだった頃の進み具合は、学習済みの語数から DAY を数え直して引き継ぎます（端数は切り捨てるので、数語は二度出ます）

## 中国語の分類（用途別の単語グループ）

全1,033語に用途のラベルを付け、検定のレベルとは別の切り口で学べるようにしています。サイドバーの「分類から学ぶ」から使います。

- 品詞でさがす（13分類）：数詞、数量詞・量詞、代名詞、疑問詞、動詞、形容詞、副詞、助動詞、介詞、接続詞、助詞・語気詞、程度・比較、知る・考える・覚える
- 場面・テーマでさがす（22分類）：あいさつ、家族、人・職業、食べ物・飲み物、買い物・お金、旅行・交通、時間・日付、学校・勉強、ことば・表現、仕事・オフィス、家・住まい、毎日の生活、体・健康、天気・季節・自然、色、方位・場所、気持ち・感情、考え・意見、趣味・スポーツ、電話・IT・メディア、動物、服・身につける物
- 1語に複数のラベルが付きます（例：「高」は形容詞、「便宜」は形容詞と買い物・お金）
- 分類の一覧は語数と代表語つきのカードで並び、開くと単語・ピンイン・意味・例文・音声がそろった一覧表になります
- 分類ページでもHSKレベル・チェックのみ・検索で絞り込めます。絞り込んだ結果がそのまま出題範囲になります（例：HSK1の数詞だけでテスト）
- 開いている分類からは、単語テスト・読解トレーニング・聴解トレーニングをそのまま始められます。単語テストは10語以上の分類ならまぎらわしい選択肢を同じ分類の中から作り、少ない分類だけ全1,033語から補います（読解・聴解の選択肢は正解と同じ級の語から作ります）
- 単語帳にも分類の絞り込みを追加し、各カードのラベルをタップするとその分類ページへ移動します
- 分類ページのURLは `#categories/travel` のように分類まで残るので、ブックマークや戻る操作で同じ一覧に戻れます

### 文法（HSK2・3）

サイドバーの「文法」、ホームの「文法（HSK2・3）」カード、分類ページ上部のカード、試験対策ページから開きます（URLは `#grammar`、単元は `#grammar/g2-18` の形）。新版HSK考试大纲の文法（HSK2 68項目・HSK3 82項目）を、易しい順に8ステップ・53単元にまとめています。

- 級ごとに★〜★★★★の4ステップ。HSK2は「文の基本と質問 → 時間と動作 → 補語の基本 → 比べる・頼む・つなぐ」、HSK3は「語と副詞を広げる → 補語を使いこなす → 特別な構文 → つなぐ・ニュアンス」
- 単元のページは、できるようになること → この単元で学ぶ文法（公式大綱の項目）→ 型カード（公式・例文・ピンイン・和訳・音声）→ よくある間違い → 確認ドリル → 前後の単元、の順です。先に学んでおく単元があれば上に出ます
- 確認ドリルは5問（語順1問・○×1問・選択問題）。8割（4問）以上で合格になり、一覧に「未着手・学習中・合格」が出ます。鍵はないので、どの単元からでも開けます
- 確認ドリルの下に「聞き取りチェック」3問があります。単元の会話（男：女：问：の形、1単元1つ）を必ず出し、残りは穴埋め（空欄のある文を見て、音声で空欄の語を聞き取る）・正誤（よくある間違いの文を聞いて正しいか判定）・意味（型カードの例文を聞いて訳を選ぶ）から違う形式を選びます。再生は他の聴解と同じく解答前2回・解答後は何度でも、解答後にスクリプトと訳が出ます。結果（最高正答率と回数）は単元のページに出ますが、合否には使いません
- 型カードの例文とよくある間違いの正しい文の▶は、録音した音声を再生します（録音がないときはブラウザの読み上げ）
- 進み具合はブラウザのローカルストレージ（`hsk-grammar-progress-v1`）に保存され、学習記録のリセットでは消えません
- 一覧の「続きから」は、解説のある単元のうち順番がいちばん早い未合格の単元を開きます
- 了の使い分け・的得地の見分け・知る考える覚える・量詞は、単元とは別の「コラム」として一覧の下に並びます
- 改修前のページのURL（`#guide/bi` など）は、対応する単元へ転送します

単元の構成と中身は `data/chinese/grammar.json`、公式大綱の項目一覧は `data/source/grammar/hsk-grammar-syllabus.json` です。型カード・ドリル・よくある間違いには、それが教える大綱の項目を `syllabus`（項目IDの配列）で付けています。

- `node scripts/check_grammar.mjs`：大綱の全項目がちょうど1つの単元に割り当てられているか、1単元5項目以内か、先に学ぶ単元が前に並ぶか、旧URLの転送先が実在するか。さらに網羅として、**全項目に印の付いた型カードとドリルが1つ以上あるか**、各単元に確認ドリル5問ぶんの問題があるか、大綱に並ぶ2文字以上の語がその級の例文に出てくるかを確認します
- `node scripts/check_guides.mjs`：解説・ドリルの中身。ピンインの音節数に加えて、**例文を辞書（1,033語）の語で区切り、語ごとに辞書のピンインと母音・声調を照合**します（一・不の変調と軽声は許容、多音字はどれかの読みに合えばよい）。○×ドリルに使う「よくある間違い」に日本語が混ざっていないか、重複していないかも確認します。単元の会話は、问：の行が質問文（prompt）と一致するか、選択肢が答え＋誤答2つか、訳があるかを確認します
- 文法の音声は `HSK_SENTENCE_ONLY=grammar node scripts/generate_sentence_audio.mjs` で作ります（文法の分だけ作り直し、ほかの音声の一覧はそのまま残します）。録音する文は `js/chinese/grammar-audio.js` の `grammarAudioTexts` で決まり（型カードの例文・よくある間違いの両方の文・穴埋めの完成文・語順ドリルの答え・会話・ステップの復習問題・見取り図・コラム）、ファイル名は文の中身から作る `grammar-xxxxxxxx.m4a` なので、並べ替えても音声はずれません。文を直したら同じコマンドを実行してください。`check_grammar.mjs` は録音のない文があるとエラーにします

改修の経緯は `docs/grammar-revamp.md` にあります。

### 解説ページ：知る・考える・覚える の使い分け

分類「知る・考える・覚える」から、または文法の一覧のコラムから開きます（URLは `#guide/cognition`）。日本語にすると同じ訳になってしまう動詞を、何を指しているかで分けます。

- 「知っている・分かる」 — 知道（情報）／认识・认得（見分けがつく）／懂・懂得（中身が分かる）／明白（腑に落ちる）／了解（詳しい）／清楚（はっきり知っている）を、よく取る目的語つきの表で比べます
- 「思う・考える」の4つ — 想／觉得（感想）／认为（判断）／以为（事実と違った思い込み）
- 「覚える・忘れる」 — 记得（状態）／记住（結果）／记（動作）／忘・忘记・别忘了
- よくある間違い4件（我知道他，我们是朋友。→ 我认识他…など）と、文法ドリル10問

分類ページの「程度・比較」「介詞」「接続詞」「動詞」「方位・場所」を開くと、対応する文法の単元へのリンクが一覧の上に出ます。

### 解説ページ：動作の様子を言う（的・得・地）

分類ページ上部のカード、助詞・語気詞の分類、または文法の一覧のコラムから開けます（URLは `#guide/de`）。

- 3つのdeを「位置」で見分ける早わかり表（的＝名詞の前、地＝動詞の前、得＝動詞の後ろ）
- 得（様態補語）の型を、肯定・否定・疑問・目的語がある場合まで11の型カードで提示します
- 「快・慢・清楚・认真・努力・安静」など、得／地といっしょによく使う様態語彙11語を、単語の音声と組み合わせ例で並べています
- ○×で並べた「よくある間違い」4件（他不跑得快。→ 他跑得不快。など）
- 「文法ドリル10問」は、この内容に合わせた3つの形式を混ぜて出題します
  - **的・得・地の3択**：空欄のある文に対し、3つのdeを「名詞の前／動詞の前／動詞のあと」の役割つきチップで選びます
  - **語順の組み立て**：〔だれが＋どんなふうに＋する＋なにを〕のようにスロットの並びを見せたうえで、語句を並べ替えます
  - **○×の判定**：「よくある間違い」から、正しい文か誤った文かを提示し、日本語の意図（例：彼は走るのが速くない）に合っているかを判断します。答え合わせで正しい形を示します
- 終了後の振り返り・間隔反復・学習記録にも反映されます

### 数量詞・量詞の特設ページ

分類「数量詞・量詞」を開くと、数の作り方とものの数え方をまとめた専用画面になります（URLは `#categories/measure`）。

- 「数詞＋量詞＋名詞」のスロット図（三 ＋ 本 ＋ 书）で語順を先に見せます
- 11〜99、100以上の零、两と二、序数、几と多少、概数、分数、小数の8つを「数の作り方」としてまとめています
- 使うときの5つのきまり（数字と名詞は直接つながらない／这・那・几・每のあとにも入る／2は两／迷ったら个／一の変調）
- 53の量詞を8グループに分け、1枚のカードに〈何を数えるか・代表フレーズ・よく数える名詞・例文・ワンポイント〉をまとめています
- 个・位・名・口、次・遍・趟、辆・台・部・架など、間違えやすい6組を比較表で見分けられます
- 「名詞から量詞を探す」逆引きで、例えば猫→只、教室→间、映画→部のように確認できます
- よく数える名詞はタップで発音、例文は収録済みの音声、短いフレーズはブラウザの音声で再生します
- 「数量詞トレーニング20問」は、スロット穴埋め10問・仕分け5問・手作りの使い分け問題5問を混ぜて出題します
- HSKレベル・検索・チェックの絞り込みは専用ページにも効きます（HSK1：14語、HSK2：25語、HSK3：14語）

## 聴解・読解トレーニング

「試験対策」ページの練習レベル（HSK 1〜3）は、出題範囲の上限だけでなく**中身の重みと形式**を変えます。

- 出題語の7割は選んだ級の語、3割は下の級の復習です（HSK1は当然100%が1級の語）。実測でHSK3を選ぶと聴解でHSK3の語が60%（語を使う問題だけなら70%）、読解で70%になります
- **1回10問の中で同じ語は出しません**。分類・チェックのように語数が10未満のときだけ、ひと通り出し切ってから繰り返します
- 誤答の選択肢は**正解と同じ級の語**から作ります（同じ級に候補が8語未満のときだけ全範囲から補います）
- 出題形式の比率も級で変えます

| 練習レベル | 聴解 | 読解 |
|---|---|---|
| HSK 1 | 単語7・例文3 | 意味4・ピンイン4・穴埋め2 |
| HSK 2 | 単語5・例文4・対話1 | 意味4・ピンイン3・穴埋め3 |
| HSK 3 | 単語3・例文5・対話2 | 意味3・ピンイン2・穴埋め5 |

対話問題は模試と同じ会話音声を使います（分類・チェックからの練習では、その語と関係がないので出しません）。

## データファイル

- 中国語：`data/chinese/` に `hsk1〜3.json` と `hsk-legacy-supplement.json`、生成元は `data/source/hsk2026/`、分類は `word-tags.json`、文法の単元は `grammar.json`（公式大綱の項目は `data/source/grammar/`）、コラムは `guides.json`、量詞ページは `measure-words.json`、作文と聴解の問題文は `practice-banks.json`、旧形式模試は `mock-hsk1〜3.json`、新形式は `mock-hsk3-v3.json`
- スペイン語：`data/spanish/dele-a1.json`、`dele-a2.json`、`dele-b1.json`

スペイン語データは `data/source/spanish-vocab/*.tsv` を編集し、`node scripts/build_spanish_vocab.mjs` でJSONを再生成できます。生成時に件数と全レベル間の重複を検証します。

分類データは `data/source/word-tags/categories.tsv`（分類の定義）と `data/source/word-tags/hsk1〜3.tsv`（公式語彙のラベル）、`data/source/hsk2026/legacy-hsk2-supplement.tsv`（旧版補完語とそのラベル）から、`node scripts/build_word_tags.mjs` で `data/chinese/word-tags.json` を再生成します。生成時に、行数・ID・見出し語・ラベルを検証し、分類ごとの語数を表示します。

文法の単元・コラム・量詞ページは `data/chinese/grammar.json`・`data/chinese/guides.json`・`data/chinese/measure-words.json` を直接編集し、`node scripts/check_guides.mjs`（中身）と `node scripts/check_grammar.mjs`（文法の構成）で検証します。参照している単語IDが実在するか、量詞の見出し・例文、ピンインの音節数、練習問題の正解を確認し、HSK1〜3にない漢字や特設ページに未掲載の量詞用法を警告します。

中国語の例文を追加・編集したら `node scripts/check_hsk_examples.mjs` で検証できます。例文・ピンイン・和訳が揃っているか、例文に見出し語が含まれるか、ピンインの音節数が漢字数と一致するか、文末記号が対応しているかを確認し、例文の重複とHSK1〜3の語彙にない漢字を警告として表示します。

`data/chinese/practice-banks.json` は作文トレーニングの20問（`writing`）と、聴解の会話・応答問題（`listeningDialogues`・`listeningResponses`）です。作文には正解の文のピンイン（`answerPinyin`）を持たせます（模試側は `scripts/build_hsk_mock_data.mjs` の表に書きます）。**配列の順番が音声ファイルの連番（`writing-bank-NNN` / `mock-dialogue-NNN` / `mock-response-NNN`）に対応する**ので、並べ替えると音声とずれます。追加するときは末尾に足して `node scripts/generate_sentence_audio.mjs` を実行してください。

`listeningResponses`（28問）と対応する `mock-response-*.m4a` は、模試が `data/chinese/mock-hsk*.json` に移ったあと出題に使われていません。聴解トレーニングに戻すか、削除するかは未決です。

学習記録はブラウザのローカルストレージに言語別で保存され、外部へ送信されません。

## 中国語模試

日本で実施されているHSK筆記1〜3級（HSK 2.0）の問題数、技能・パート別の出題数、制限時間、合格基準に合わせています。写真問題は写真素材を使わず、意味を直接表示しない簡易イラスト記号で代替しています。

HSK3は旧形式を残したまま、**HSK 3.0の公式サンプルに合わせた70問版**も併設しています。新形式は聴解30問（約23分）・読解30問（30分）・作文10問（20分）で、作文はピンインから漢字を書く5問と、図・指定語を使って一文を作る5問です。旧・新形式とも `node scripts/build_hsk_mock_data.mjs` で一括再生成できます。

- HSK2聴解は第1・2部分を各10問、第3部分を34問、第4部分を15問収録し、本番の部分別比率を保って受験ごとに35問をランダム抽出します。プールの会話は場面も設問の種類も互いに異なり、1回の模試で似た問題が続きません（単語1語ずつの聴き取りは模試ではなく聴解トレーニングが担当します）
- HSK3聴解は第3部分を20問のプールにし、受験ごとに10問をランダム抽出します（第1・2・4部分は固定10問ずつ）。HSK1は固定問題です
- **HSK3作文は60問のプール**（第1部分＝並べ替え30問、第2部分＝漢字書き30問）から、受験ごとに5問ずつ計10問を抽出します。200回引いて全60問が出ること、出題回数の偏りが±4σに収まることを確認しています
- 作文の作問はビルド時に基準を検査します。**第1部分は語句を1〜3字に割り**（難しいところを組み上げた状態で渡さない）、**各問が文法点をひとつ以上ねらい**（把・被・比較・様態補語・結果/方向補語・複文・兼語・是…的・存現文・連動文など）、語句を並べ替えると正解になること。**第2部分で書かせる漢字はHSK2〜3相当**に限ります（1級の字は易しすぎるため）
- 完成句子で**語順が複数ありうる問題には別解を持たせ**、どちらで答えても正解になります（例：「如果明天下雨我就不去了。」と「明天如果下雨我就不去了。」）
- 1回の模試の中で、技能・部分をまたいで同じ言い回し（6文字以上）を使い回しません。聴解で聞いた文が読解の穴埋めや作文の並べ替えに再登場しないことをビルド時に検査します
- HSK1・3は本文・選択肢の漢字をその級までの語彙に収め、字はHSK1〜3にあってもHSK4以上の語（楼梯・味道・提前・差不多など）はビルドを失敗させます。人名・地名（王・李・上海）だけ例外です
- 同じ場面の語が1回の模試に何問出るかを数え、目安（4問）を超えると警告します（HSK2の本文整理は今後の課題）
- 選択肢は模試を開始するたびに並べ替えます（対错を選ぶ「对／不对」だけは順序を固定）
- 穴埋め問題は文脈から答えが一つに決まるように作問し、選択肢は同じ品詞・同じ級の語でそろえています
- HSK2読解は本番の構成に合わせ、第1部分＝図示選択5問、第2部分＝選詞填空5問、第3部分＝判断对错5問（本文＋★の文）、第4部分＝句子匹配10問です
- 模試中は中国語の指示の下に、その部分の解き方を日本語で短く添えます
- 模試用の聴解129問は収録音声を試験速度で自動的に2回再生します
- 対話音声は話者の切り替わりで0.45秒、設問（问：〜）の前で1.2秒の間を空けます
- HSK1・2の読解問題ではピンインを併記します
- 聴解・読解・作文はセクションごとに時間を管理し、時間切れになると次のセクションへ進みます
- 各級のカードの下のボタンから、聴解だけ・読解だけ・作文だけを本番と同じ問数・制限時間で受けられます（100点満点換算、6割が目安。学習記録の模試履歴にも技能名つきで残ります）
- 聴解は解答すると**音声のスクリプトが出て、何度でも聞き直せます**（勉強用のため。対話は話者ごとに行を分けて表示します）
- 作文は解答すると**正解の文・ピンイン・日本語の意味・「正解を聞く」ボタン**が出ます（第2部分は空欄に漢字を入れた完成文を表示。読み上げは収録音声 `audio/sentences/hsk3-wN-NN-answer.m4a`（60問ぶん収録））
- 作文第1部分の語句は**タップで文に入れ、ドラッグで順番の入れ替え**ができます。置いた語句をもう一度タップするか、候補の枠へドラッグすると戻せます。ドラッグ中は入る位置に縦棒が出ます。マウスと指の両方で同じように動きます（HTML5のドラッグではなくポインタ操作で作っているため、スマホでも使えます）
- 解答すると、選んだ答えと正解が色で分かります（勉強用のため。解説は終了後の振り返りで確認します）。前のセクションへは戻れません
- 時間切れで飛ばした問題は振り返りに「未回答」として残ります

表示得点は各技能の正答率を100点に換算した自己採点用の目安で、公式成績を保証するものではありません。模試データは `scripts/build_hsk_mock_data.mjs` で件数・重複・語彙を検証しながら再生成できます。聴解の原文を変えたら `scripts/generate_sentence_audio.sh` で音声を作り直してください（内容が変わった問題だけ再生成されます）。

現時点で本番と違うのは、読解第1・2部分をA〜Eの共通選択肢ではなく毎問3択にしている点、聴解第1部分を対話ではなく1文＋記号イラストにしている点、推断（关系・职业・态度）を問う設問がまだ3問しかない点です。

## 中国語音声の再生成

単語音声は `scripts/generate_audio.sh`、例文・模試音声は `scripts/generate_sentence_audio.sh` で再生成できます。音声は `say` でWAVを作ってから `afconvert` でAAC 48kbps（`.m4a`）に変換して保存します（ビットレートは `HSK_AUDIO_BITRATE` / `HSK_SENTENCE_AUDIO_BITRATE` で変更できます）。詳細な音声・速度設定は各スクリプト冒頭を参照してください。内容が変わっていない音声は `audio/manifest.json` を見て再利用し、`say` が応答しなくなった場合は60秒で打ち切って最大3回まで再試行します。

HSK3で追加した256語は、現行macOSでも外部コーデックなしで再生成できるよう `node scripts/generate_hsk3_context_audio.mjs` でWAV収録します。公式語彙・量詞・文法・新模試・500語分の音声をまとめて確認する最終監査は `node scripts/check_hsk3_official_coverage.mjs` です。

音声形式の選定理由と実測データは [docs/audio.md](docs/audio.md) にまとめています。

音声はmacOSの `say` コマンドで生成し、例文・模試では女性役と設問に **Tingting**、男性役に中国本土向けの **Reed** を使います。リスニング会話では問題文と問いの間に、英語音声 **Question** を挟みます。Reedが未導入の場合は「システム設定 → アクセシビリティ → 読み上げコンテンツ → システムの声 → 管理…」でダウンロードしてください。別の声に変える場合は `HSK_AUDIO_VOICE`、`HSK_SENTENCE_FEMALE_VOICE`、`HSK_SENTENCE_MALE_VOICE`、`HSK_SENTENCE_CUE_VOICE` で指定できます。
