# 言語アプリ

中国語（HSK 1〜3級）とスペイン語（DELE A1〜B1相当）を、依存関係なしで学べるブラウザアプリです。

公開版: https://nagomen.github.io/language-study-app/

## 起動方法

ブラウザで上記URLを開くか、ローカルで動かす場合は `スタート.command` をダブルクリックしてください。言語選択画面がブラウザで開きます。

初回のみmacOSに止められた場合は、ファイルを右クリックして「開く」を選択してください。

## デプロイ

GitHub Pages（`main` ブランチのルートをそのまま配信）です。更新はpushするだけで反映されます。

```
git add -A
git commit -m "変更内容"
git push
```

反映まで1〜2分かかります。ビルド状況は https://github.com/nagomen/language-study-app/actions で確認できます。

すべて相対パスで動く静的サイトなので、ビルド工程はありません。学習記録・チェックはブラウザのローカルストレージに保存されるため、公開版とローカル版では別々に記録されます。

## 収録内容

- 中国語：HSK 1〜3級、合計600語。例文、固定44.1kHz音声、聴解・読解・作文、写真なし本番形式模試、間隔反復
- スペイン語：DELE A1相当150語、A2相当150語、B1相当300語。レベル別クイズ、検索、スペイン語音声、まちがい復習、学習記録

単語テストは解答するたびに、その単語を使った例文（中国語・ピンイン・和訳）を答えと一緒に表示し、その場で音声を再生できます。出題語は例文中でハイライトされます。例文はHSK1〜3の全600語に収録しています。

単語テスト・聴解／読解／作文トレーニング・間隔反復・模試・スペイン語クイズのすべてで、終了画面に「振り返り」が表示されます。1問ずつ、問題文（聴解は音声原文）、自分の回答、正解、解説を並べ、「すべて／まちがい」で絞り込めます。聴解・単語の問題は振り返り画面から音声を再生し直せます。

単語一覧・例文集・テスト後の振り返りにある ✓ ボタンで、気になった単語にチェックを付けられます。チェックした単語は「チェック」ページに集まり、例文・正誤の記録・次の復習日を見返せるほか、そのまま単語テスト／読解／聴解で出題できます（誤答の選択肢は全600語から作るので、チェックが少なくても問題が成立します）。単語一覧と例文集は「チェックのみ」で絞り込めます。スペイン語も単語一覧と振り返りからチェックでき、チェックした単語だけでテストできます。

チェックは学習記録とは別に保存され、学習記録のリセットでは消えません。消すときは「チェック」ページの「チェックをすべて解除」を使います。

スペイン語語彙はInstituto Cervantes「Plan Curricular」の分野別インベントリを設計基準にした独自の学習用リストです。DELEには単一の公式固定出題語彙表がないため、「DELE相当」と表記しています。

## データファイル

- 中国語：`data/hsk1.json`、`data/hsk2.json`、`data/hsk3.json`
- スペイン語：`data/dele-a1.json`、`data/dele-a2.json`、`data/dele-b1.json`

スペイン語データは `scripts/spanish_vocab/*.tsv` を編集し、`node scripts/build_spanish_vocab.mjs` でJSONを再生成できます。生成時に件数と全レベル間の重複を検証します。

中国語の例文を追加・編集したら `node scripts/check_hsk_examples.mjs` で検証できます。例文・ピンイン・和訳が揃っているか、例文に見出し語が含まれるか、ピンインの音節数が漢字数と一致するか、文末記号が対応しているかを確認し、例文の重複とHSK1〜3の語彙にない漢字を警告として表示します。

学習記録はブラウザのローカルストレージに言語別で保存され、外部へ送信されません。

## 中国語模試

日本で実施されているHSK筆記1〜3級（HSK 2.0）の問題数、技能・パート別の出題数、制限時間、合格基準に合わせています。写真問題は写真素材を使わず、意味を直接表示しない簡易イラスト記号で代替しています。

- 級別に独立した180問を収録し、同じ模試内では聴解原文を重複させません
- 聴解95問は固定44.1kHz音声を試験速度で自動的に2回再生します
- HSK1・2の読解問題ではピンインを併記します
- 聴解・読解・作文はセクションごとに時間を管理し、時間切れになると次のセクションへ進みます
- 模試中に正解は表示せず、前のセクションへ戻れません（正解と音声原文は終了後の振り返りで確認します）
- 時間切れで飛ばした問題は振り返りに「未回答」として残ります

表示得点は各技能の正答率を100点に換算した自己採点用の目安で、公式成績を保証するものではありません。模試データは `scripts/build_hsk_mock_data.mjs` で件数・重複を検証しながら再生成できます。

## 中国語音声の再生成

単語音声は `scripts/generate_audio.sh`、例文・模試音声は `scripts/generate_sentence_audio.sh` で再生成できます。詳細な音声・速度設定は各スクリプト冒頭を参照してください。内容が変わっていない音声は `audio/manifest.json` を見て再利用し、`say` が応答しなくなった場合は60秒で打ち切って最大3回まで再試行します。

音声はmacOSの `say` コマンドの **Tingting**（中国語）で生成します。SandyやReedといった新しい声は、音声データを「システム設定 → アクセシビリティ → 読み上げコンテンツ → システムの声 → 管理…」でダウンロードしていない端末では低品質な代替音で合成されるため、既定では使いません。別の声に変える場合は `HSK_AUDIO_VOICE`、`HSK_SENTENCE_FEMALE_VOICE`、`HSK_SENTENCE_MALE_VOICE` で指定し、収録済み音声と声が混ざらないよう全ファイルを再生成してください。
