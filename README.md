# 言語アプリ

中国語（HSK 1〜3級）とスペイン語（DELE A1〜B1相当）を、依存関係なしで学べるブラウザアプリです。

公開版: https://nagomen.github.io/language-study-app/

## 起動方法

ブラウザで上記URLを開くか、ローカルで動かす場合は `スタート.command` をダブルクリックしてください。言語選択画面がブラウザで開きます。

初回のみmacOSに止められた場合は、ファイルを右クリックして「開く」を選択してください。

## デプロイ

GitHub Pages（`main` ブランチのルートをそのまま配信）です。更新はpushするだけで反映されます。

```
git add -A
git commit -m "変更内容"
git push
```

反映まで1〜2分かかります。ビルド状況は https://github.com/nagomen/language-study-app/actions で確認できます。

すべて相対パスで動く静的サイトなので、ビルド工程はありません。学習記録・チェックはブラウザのローカルストレージに保存されるため、公開版とローカル版では別々に記録されます。

## ファイル構成

ビルド工程はなく、HTMLが直接スクリプトを読みます。

| ファイル | 役割 |
|---|---|
| `index.html` / `portal.css` | 言語を選ぶ入口 |
| `chinese.html` / `styles.css` | 中国語のページ |

中国語ページは `js/chinese/main.js` を入口に、機能ごとのモジュールへ分かれています。

## 収録内容

- 中国語：HSK 1〜3級、合計600語。例文つきの単語帳、収録音声（AAC 48kbps）、HSK3の毎日20語、用途別の分類（34種）、文法ガイドと量詞の特設ページ、聴解・読解・作文、写真なし本番形式模試、間隔反復
- スペイン語：DELE A1相当150語、A2相当150語、B1相当300語。レベル別クイズ、検索、スペイン語音声、まちがい復習、学習記録

「単語帳」ページはHSK1〜3の600語を1語1枚のカードで表示します。1枚に漢字・ピンイン・意味・分類ラベルと、その語を使った例文（中国語・ピンイン・和訳・音声）が入ります。レベル・分類・チェックのほか、例文の本文や和訳でも検索できます。「意味をかくす」を押すと意味・ラベル・例文が隠れ、カードをタップするとめくって確認できます（かつての「例文集」ページはこの単語帳に統合しました）。

単語テストは解答するたびに、その単語を使った例文（中国語・ピンイン・和訳）を答えと一緒に表示し、その場で音声を再生できます。出題語は例文中でハイライトされます。例文はHSK1〜3の全600語に収録しています。

聴解の問題は、解答する前は音声を2回まで、**解答したあとは回数制限なしで**聞き直せます。

単語テスト・聴解／読解／作文トレーニング・間隔反復・模試・スペイン語クイズのすべてで、終了画面に「振り返り」が表示されます。1問ずつ、問題文（聴解は音声原文）、自分の回答、正解、解説を並べ、「すべて／まちがい」で絞り込めます。聴解・単語の問題は振り返り画面から音声を再生し直せます。

単語帳・テスト後の振り返りにある ✓ ボタンで、気になった単語にチェックを付けられます。チェックした単語は「チェック」ページに集まり、例文・正誤の記録・次の復習日を見返せるほか、そのまま単語テスト／読解／聴解で出題できます（誤答の選択肢は全600語から作るので、チェックが少なくても問題が成立します）。単語帳は「チェックのみ」で絞り込めます。スペイン語も単語一覧と振り返りからチェックでき、チェックした単語だけでテストできます。

チェックは学習記録とは別に保存され、学習記録のリセットでは消えません。消すときは「チェック」ページの「チェックをすべて解除」を使います。

チェックはブラウザのローカルストレージ（中国語 `hsk-checked-words`、スペイン語 `language-app-spanish-checked-v1`）に単語IDの配列として保存されるため、端末やURL（ローカル版と公開版）をまたいでは共有されません。「チェック」ページの「チェックを書き出す（JSON）」でファイルに保存し、別の環境で「チェックを読み込む」から取り込めます。読み込みは既存のチェックへの追加で、この単語データに無いIDは無視します。

スペイン語語彙はInstituto Cervantes「Plan Curricular」の分野別インベントリを設計基準にした独自の学習用リストです。DELEには単一の公式固定出題語彙表がないため、「DELE相当」と表記しています。

## 毎日20語（HSK3）

ホームの上部にある「今日の20語」から始めます（URLは `#daily`）。HSK3の300語を、20語ずつ15日で一周する仕組みです。

- **日ごとの20語は固定で、重複しません。** 300語を固定の並べ替えで15セットに分けているので、同じ単語が新出として二度出ることはありません（並びは何度開いても同じです）
- **前回まちがえた単語が翌日の出題に入ります。** その日は「もう一度出す語 → 今日の20語」の順に1語1問ずつ出題します
- **正解した単語でも、気になる ✓ を付ければまちがい扱いで次回に出ます。** テスト中の答え合わせ画面と終了後の振り返り、単語帳などの ✓ ボタンから付けられます（まだ学んでいない先の日の単語は前倒しされません）
- まちがえた単語も ✓ を付けた単語も**正解するまで持ち越し**ます。正解した時点で次回の出題から外れます（✓ 自体は残るので、また出したいときは付け直します）
- **1日1セットです。** その日のテストを終えると次の20語は翌日まで開かず、ページは「今日学んだ20語」の見直しに切り替わります（同じ20語の解き直しと、まちがえた単語だけの復習はいつでもできます。どちらも日付は進みません）
- テストをしなかった日は進みません。1日空いても3日空いても、次に開いたときは同じ DAY の20語から始まります
- **最後まで解かずにやめた回は完了になりません。** 同じ問題（その日の20語＋持ち越し）がもう一度出ます。途中で × を押すと「残り◯問・完了になりません」と確認が出て、やめると毎日20語のページに戻ります（答えた分の正誤は学習記録と間隔反復には残ります）
- ページには今日の20語と前回のまちがいが、例文・音声・✓ボタンつきで並びます。テスト前の下読みに使えます
- 15日ぶんを終えると完了表示に変わり、まちがえた単語の復習だけを続けられます。「毎日20語の進み具合をリセット」でDAY 1からやり直せます
- 学習記録・間隔反復・まちがい復習にも通常のテストと同じように反映されます
- 進み具合はブラウザのローカルストレージ（`hsk3-daily-v1`）に保存され、学習記録のリセットでは消えません

## 中国語の分類（用途別の単語グループ）

HSK1〜3の全600語に用途のラベルを付け、検定のレベルとは別の切り口で学べるようにしています。サイドバーの「分類から学ぶ」から使います。

- 品詞でさがす（12分類）：数詞、量詞（助数詞）、代名詞、疑問詞、動詞、形容詞、副詞、助動詞、介詞、接続詞、助詞・語気詞、程度・比較
- 場面・テーマでさがす（22分類）：あいさつ、家族、人・職業、食べ物・飲み物、買い物・お金、旅行・交通、時間・日付、学校・勉強、ことば・表現、仕事・オフィス、家・住まい、毎日の生活、体・健康、天気・季節・自然、色、方位・場所、気持ち・感情、考え・意見、趣味・スポーツ、電話・IT・メディア、動物、服・身につける物
- 1語に複数のラベルが付きます（例：「高」は形容詞、「便宜」は形容詞と買い物・お金）
- 分類の一覧は語数と代表語つきのカードで並び、開くと単語・ピンイン・意味・例文・音声がそろった一覧表になります
- 分類ページでもHSKレベル・チェックのみ・検索で絞り込めます。絞り込んだ結果がそのまま出題範囲になります（例：HSK1の数詞だけでテスト）
- 開いている分類からは、単語テスト・読解トレーニング・聴解トレーニングをそのまま始められます。単語テストは10語以上の分類ならまぎらわしい選択肢を同じ分類の中から作り、少ない分類だけ全600語から補います（読解・聴解の選択肢は正解と同じ級の語から作ります）
- 単語帳にも分類の絞り込みを追加し、各カードのラベルをタップするとその分類ページへ移動します
- 分類ページのURLは `#categories/travel` のように分類まで残るので、ブックマークや戻る操作で同じ一覧に戻れます

### 解説ページ：HSK3の必修文法

ホームの「HSK3の必修文法」カード、分類ページ上部のカード、試験対策ページのトレーニングの下、の3か所から開きます（URLは `#guide/hsk3-grammar`）。HSK3で問われる文法を6つのトピックに分け、まとめページを入口にしています。

- まとめページには、6トピックへの目次、HSK3の文の骨組み（主語→時間→場所・相手→動詞→補語→目的語）の表、トピックをまたいで間違えやすい型の○×、そして「動作の様子（的・得・地）」「量詞」への関連リンクが入ります
- 各トピックのページは、早わかり表 → 型カード（公式・例文・ピンイン・和訳・音声・注意点）→ よくある間違いの○× という同じ組み立てです
- どのページにも「文法ドリル10問」があり、3択・語順の組み立て・○×の判定を混ぜて出題します（3つの形式が必ず混ざります）
- トピックのページからは「← HSK3の必修文法へ戻る」でまとめページに戻ります。各ページのURLは `#guide/le` のように残ります

| トピック | URL | 扱う内容 |
|---|---|---|
| 了：終わったことと変わったこと | `#guide/le` | 動詞＋了と文末の了、否定の没、还没…呢、快…了 |
| 比べる言い方 | `#guide/bi` | A比B＋形容詞、一点儿／得多／数量、跟…一样、没有…那么 |
| 把構文 | `#guide/ba` | 把＋物＋動詞＋結果、在／到／给、否定の位置、把が使えない動詞 |
| 3つの補語 | `#guide/complement` | 結果補語（完・到・见・好・懂・错・清楚）、方向補語、可能補語 |
| 是…の構文と存在 | `#guide/shi-de` | 是…的、有と在の使い分け、存現文（場所＋動詞＋了／着） |
| 文をつなぐ（複文） | `#guide/conjunction` | 因为…所以、虽然…但是、如果…就ほか8組と、就・也の位置 |

分類ページの「程度・比較」「介詞」「接続詞」「動詞」「方位・場所」を開くと、対応する解説ページへのリンクが一覧の上に出ます。

### 解説ページ：動作の様子を言う（的・得・地）

分類ページ上部のカード、助詞・語気詞の分類、またはHSK3必修文法のまとめページから開けます（URLは `#guide/de`）。

- 3つのdeを「位置」で見分ける早わかり表（的＝名詞の前、地＝動詞の前、得＝動詞の後ろ）
- 得（様態補語）の型を、肯定・否定・疑問・目的語がある場合まで11の型カードで提示します
- 「快・慢・清楚・认真・努力・安静」など、得／地といっしょによく使う様態語彙11語を、単語の音声と組み合わせ例で並べています
- ○×で並べた「よくある間違い」4件（他不跑得快。→ 他跑得不快。など）
- 「文法ドリル10問」は、この内容に合わせた3つの形式を混ぜて出題します
  - **的・得・地の3択**：空欄のある文に対し、3つのdeを「名詞の前／動詞の前／動詞のあと」の役割つきチップで選びます
  - **語順の組み立て**：〔だれが＋どんなふうに＋する＋なにを〕のようにスロットの並びを見せたうえで、語句を並べ替えます
  - **○×の判定**：「よくある間違い」から、正しい文か誤った文かを提示し、日本語の意図（例：彼は走るのが速くない）に合っているかを判断します。答え合わせで正しい形を示します
- 終了後の振り返り・間隔反復・学習記録にも反映されます

### 量詞（助数詞）の特設ページ

分類「量詞（助数詞）」を開くと、単語の一覧ではなく量詞専用の画面になります（URLは `#categories/measure`）。

- 「数詞＋量詞＋名詞」のスロット図（三 ＋ 本 ＋ 书）で語順を先に見せます
- 使うときの4つのきまり（数字と名詞は直接つながらない／这・那・几のあとにも入る／2は两／迷ったら个）
- 27の量詞を「もの・人」「時間・日づけ」「お金」「単位・回数」の4グループに分け、1枚のカードに〈何を数えるか・代表フレーズ・よく数える名詞・例文・ワンポイント〉をまとめています
- よく数える名詞はタップで発音、例文は収録済みの音声、短いフレーズはブラウザの音声で再生します
- 「量詞クイズ10問」も量詞の覚え方に合わせた3形式です
  - **スロット穴埋め（5問）**：「三 ＋ □ ＋ 书」の形を見せ、空いた□に入る量詞をピンインつきのチップから選びます。数詞は声調が変わらない「三」で固定し、量詞だけに集中できるようにしています
  - **仕分け（2問）**：「张で数えるものをすべて選ぶ」を6択から複数選択で答えます。誤答にはその量詞では数えられない名詞だけを入れているので、まとまりごと覚えられます
  - **時間・お金（3問）**：两个小时・十分钟・八号など、引っかかりやすい手作りの問題です
- HSKレベルやチェックの絞り込みは量詞ページにも効きます（HSK1だけなら8語）

## 聴解・読解トレーニング

「試験対策」ページの練習レベル（HSK 1〜3）は、出題範囲の上限だけでなく**中身の重みと形式**を変えます。

- 出題語の7割は選んだ級の語、3割は下の級の復習です（HSK1は当然100%が1級の語）。実測でHSK3を選ぶと聴解でHSK3の語が60%（語を使う問題だけなら70%）、読解で70%になります
- **1回10問の中で同じ語は出しません**。分類・チェックのように語数が10未満のときだけ、ひと通り出し切ってから繰り返します
- 誤答の選択肢は**正解と同じ級の語**から作ります（同じ級に候補が8語未満のときだけ全範囲から補います）
- 出題形式の比率も級で変えます

| 練習レベル | 聴解 | 読解 |
|---|---|---|
| HSK 1 | 単語7・例文3 | 意味4・ピンイン4・穴埋め2 |
| HSK 2 | 単語5・例文4・対話1 | 意味4・ピンイン3・穴埋め3 |
| HSK 3 | 単語3・例文5・対話2 | 意味3・ピンイン2・穴埋め5 |

対話問題は模試と同じ会話音声を使います（分類・チェックからの練習では、その語と関係がないので出しません）。

## データファイル

- 中国語：`data/hsk1.json`、`data/hsk2.json`、`data/hsk3.json`、分類は `data/word-tags.json`、解説ページは `data/guides.json`、量詞ページは `data/measure-words.json`、作文と聴解の問題文は `data/practice-banks.json`
- スペイン語：`data/dele-a1.json`、`data/dele-a2.json`、`data/dele-b1.json`

スペイン語データは `scripts/spanish_vocab/*.tsv` を編集し、`node scripts/build_spanish_vocab.mjs` でJSONを再生成できます。生成時に件数と全レベル間の重複を検証します。

分類データは `scripts/word_tags/categories.tsv`（分類の定義）と `scripts/word_tags/hsk1〜3.tsv`（単語ごとのラベル）を編集し、`node scripts/build_word_tags.mjs` で `data/word-tags.json` を再生成します。生成時に、行数と単語データの並びが一致するか、見出し語がずれていないか、未定義のラベルや無ラベルの単語がないかを検証し、分類ごとの語数を表示します。

解説ページと量詞ページは `data/guides.json`・`data/measure-words.json` を直接編集し、`node scripts/check_guides.mjs` で検証します。参照している単語IDが実在するか、量詞ページが measure ラベルの27語を漏れなく扱っているか、例文のピンインの音節数が漢字数と一致するか、練習問題の正解が選択肢に1つだけ入っているかを確認し、HSK1〜3にない漢字を警告します。

中国語の例文を追加・編集したら `node scripts/check_hsk_examples.mjs` で検証できます。例文・ピンイン・和訳が揃っているか、例文に見出し語が含まれるか、ピンインの音節数が漢字数と一致するか、文末記号が対応しているかを確認し、例文の重複とHSK1〜3の語彙にない漢字を警告として表示します。

`data/practice-banks.json` は作文トレーニングの20問（`writing`）と、聴解の会話・応答問題（`listeningDialogues`・`listeningResponses`）です。**配列の順番が音声ファイルの連番（`writing-bank-NNN` / `mock-dialogue-NNN` / `mock-response-NNN`）に対応する**ので、並べ替えると音声とずれます。追加するときは末尾に足して `node scripts/generate_sentence_audio.mjs` を実行してください。

`listeningResponses`（28問）と対応する `mock-response-*.m4a` は、模試が `data/mock-hsk*.json` に移ったあと出題に使われていません。聴解トレーニングに戻すか、削除するかは未決です。

学習記録はブラウザのローカルストレージに言語別で保存され、外部へ送信されません。

## 中国語模試

日本で実施されているHSK筆記1〜3級（HSK 2.0）の問題数、技能・パート別の出題数、制限時間、合格基準に合わせています。写真問題は写真素材を使わず、意味を直接表示しない簡易イラスト記号で代替しています。

- HSK2聴解は第1・2部分を各10問、第3部分を34問、第4部分を15問収録し、本番の部分別比率を保って受験ごとに35問をランダム抽出します。プールの会話は場面も設問の種類も互いに異なり、1回の模試で似た問題が続きません（単語1語ずつの聴き取りは模試ではなく聴解トレーニングが担当します）
- HSK3聴解は第3部分を20問のプールにし、受験ごとに10問をランダム抽出します（第1・2・4部分は固定10問ずつ）。HSK1は固定問題です
- 1回の模試の中で、技能・部分をまたいで同じ言い回し（6文字以上）を使い回しません。聴解で聞いた文が読解の穴埋めや作文の並べ替えに再登場しないことをビルド時に検査します
- HSK1・3は本文・選択肢の漢字をその級までの語彙に収め、字はHSK1〜3にあってもHSK4以上の語（楼梯・味道・提前・差不多など）はビルドを失敗させます。人名・地名（王・李・上海）だけ例外です
- 同じ場面の語が1回の模試に何問出るかを数え、目安（4問）を超えると警告します（HSK2の本文整理は今後の課題）
- 選択肢は模試を開始するたびに並べ替えます（対错を選ぶ「对／不对」だけは順序を固定）
- 穴埋め問題は文脈から答えが一つに決まるように作問し、選択肢は同じ品詞・同じ級の語でそろえています
- HSK2読解は本番の構成に合わせ、第1部分＝図示選択5問、第2部分＝選詞填空5問、第3部分＝判断对错5問（本文＋★の文）、第4部分＝句子匹配10問です
- 模試中は中国語の指示の下に、その部分の解き方を日本語で短く添えます
- 模試用の聴解129問は収録音声を試験速度で自動的に2回再生します
- 対話音声は話者の切り替わりで0.45秒、設問（问：〜）の前で1.2秒の間を空けます
- HSK1・2の読解問題ではピンインを併記します
- 聴解・読解・作文はセクションごとに時間を管理し、時間切れになると次のセクションへ進みます
- 各級のカードの下のボタンから、聴解だけ・読解だけ・作文だけを本番と同じ問数・制限時間で受けられます（100点満点換算、6割が目安。学習記録の模試履歴にも技能名つきで残ります）
- 聴解は解答すると**音声のスクリプトが出て、何度でも聞き直せます**（勉強用のため。対話は話者ごとに行を分けて表示します）
- 作文は解答すると**正解の文・日本語の意味・「正解を聞く」ボタン**が出ます（第2部分は空欄に漢字を入れた完成文を表示。読み上げは収録音声 `audio/sentences/hsk3-wN-NN-answer.m4a`）
- 作文第1部分の語句は**クリックで追加、ドラッグで順番の入れ替え**ができます。並べた語句をもう一度クリックするか、候補の枠へドラッグすると戻せます
- 解答すると、選んだ答えと正解が色で分かります（勉強用のため。解説は終了後の振り返りで確認します）。前のセクションへは戻れません
- 時間切れで飛ばした問題は振り返りに「未回答」として残ります

表示得点は各技能の正答率を100点に換算した自己採点用の目安で、公式成績を保証するものではありません。模試データは `scripts/build_hsk_mock_data.mjs` で件数・重複・語彙を検証しながら再生成できます。聴解の原文を変えたら `scripts/generate_sentence_audio.sh` で音声を作り直してください（内容が変わった問題だけ再生成されます）。

現時点で本番と違うのは、読解第1・2部分をA〜Eの共通選択肢ではなく毎問3択にしている点、聴解第1部分を対話ではなく1文＋記号イラストにしている点、推断（关系・职业・态度）を問う設問がまだ3問しかない点です。

## 中国語音声の再生成

単語音声は `scripts/generate_audio.sh`、例文・模試音声は `scripts/generate_sentence_audio.sh` で再生成できます。音声は `say` でWAVを作ってから `afconvert` でAAC 48kbps（`.m4a`）に変換して保存します（ビットレートは `HSK_AUDIO_BITRATE` / `HSK_SENTENCE_AUDIO_BITRATE` で変更できます）。詳細な音声・速度設定は各スクリプト冒頭を参照してください。内容が変わっていない音声は `audio/manifest.json` を見て再利用し、`say` が応答しなくなった場合は60秒で打ち切って最大3回まで再試行します。

音声形式の選定理由と実測データは [docs/audio.md](docs/audio.md) にまとめています。

音声はmacOSの `say` コマンドで生成し、例文・模試では女性役と設問に **Tingting**、男性役に中国本土向けの **Reed** を使います。リスニング会話では問題文と問いの間に、英語音声 **Question** を挟みます。Reedが未導入の場合は「システム設定 → アクセシビリティ → 読み上げコンテンツ → システムの声 → 管理…」でダウンロードしてください。別の声に変える場合は `HSK_AUDIO_VOICE`、`HSK_SENTENCE_FEMALE_VOICE`、`HSK_SENTENCE_MALE_VOICE`、`HSK_SENTENCE_CUE_VOICE` で指定できます。
